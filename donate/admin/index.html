A page view counts when the page has opened in a real browser: it tells the server so itself, without a cookie or an id - robots that never run it, and scripts, are left out. A visitor is a hash of address and browser with a secret salt (no address is kept); single visits are kept 30 days, the counts per day ten years. Your own visits are left out: this browser (it opened this page), your own network, and STATS_IGNORE. Countries: IP Geolocation by DB-IP. Donations come from Stripe.
