A page view counts when the page has opened in a real browser: it tells the server so itself, without a cookie or an id - robots that never run it, and scripts, are left out. Likely robots that do run pages - a browser without a screen, or a Chrome, Edge or Firefox more than two years out of date, unless a pointer, touch or key said a person was there - are kept and marked, but not counted. The pages also tell which help questions are opened, what the help is searched for, how far down the front page a visit gets, which install steps are opened, a language switched and a link to another site followed - what, never who. A visitor is a hash of address and browser with a secret salt (no address is kept, the hashes 25 months); single visits are kept 13 months, then only without anything that points to a person, like the counts per day, for good. Your own visits are left out: this browser (it opened this page), your own network, and STATS_IGNORE. Countries: IP Geolocation by DB-IP. Donations come from Stripe.
